leancheck

LeanCheck is an enumerative property-based testing library. It can be used to complement your unit tests.

The usual drill in unit testing involves making assertions about specific input-output cases of functions, such as:

assertEqual(sorted([4,2,1,3]), [1,2,3,4])

There are no arguments to the unit test.

In property-based testing (with LeanCheck) one writes more general properties that should be true for a given set of arguments. Properties in this sense are parameterized unit tests or parameterized assertions.

For example: given any list, sorting it twice is the same as sorting it once. We can encode this as a function returning a boolean value:

>>> def prop_sorted_twice(xs: list[int]) -> bool:
...     return sorted(sorted(xs)) == sorted(xs)

For whatever list we provide this function, it should return True. Now one can use LeanCheck to verify this automatically:

>>> check(prop_sorted_twice)
+++ OK, passed 360 tests: prop_sorted_twice
True

LeanCheck automatically came up with 360 unique lists to exercise the property.

When the property or function-under-test is incorrect LeanCheck may find and report a counterexample:

>>> def prop_sorted_wrong(xs: list[int]) -> bool:
...     return sorted(xs) == xs
...

>>> check(prop_sorted_wrong)
*** Failed! Falsifiable after 7 tests:
    prop_sorted_wrong([1, 0])
False

We now know that an ill input is the list [1, 0]. In this arbitrary example, the property is incorrect. In cases where the property is indeed correct, the counterexample indicates a bug.

If you have a collection of properties (prop_*) in a Python file, just call leancheck.main() and all of them will be automatically tested. In the case of a library, you can put everything under an if-expression as you would do with unittest.main() or doctest.testmod().

if __name__ == '__main__':
    leancheck.main()

LeanCheck is available on PyPI and installable via:

$ pip install leancheck

 28class Enumerator:
 29    """
 30    This class enumerates test values.
 31
 32    Enumerations are represented internally as
 33    [a (potentially infinite) generator of finite lists](https://matela.com.br/thesis-rudy.pdf):
 34    tiers of values of increasing size.
 35    This is needed in order for the enumeration to be fair.
 36
 37    As a user, you can query available enumerations
 38    by passing a type as the class constructor argument.
 39
 40    >>> Enumerator(int)
 41    Enumerator(lambda: (xs for xs in [[0], [1], [-1], [2], [-2], [3], ...]))
 42
 43    >>> Enumerator(bool)
 44    Enumerator(lambda: (xs for xs in [[False, True]]))
 45
 46    >>> print(Enumerator(list[int]))
 47    [[], [0], [0, 0], [1], [0, 0, 0], [0, 1], ...]
 48
 49    >>> print(Enumerator(tuple[bool, int]))
 50    [(False, 0), (True, 0), (False, 1), (True, 1), (False, -1), (True, -1), ...]
 51
 52    >>> print(Enumerator(tuple[int,int,int]))
 53    [(0, 0, 0), (0, 0, 1), (0, 1, 0), (1, 0, 0), (0, 0, -1), (0, 1, 1), ...]
 54
 55    Nesting can be arbitrary:
 56
 57    >>> print(Enumerator(list[list[int]]))
 58    [[], [[]], [[], []], [[0]], [[], [], []], [[], [0]], ...]
 59
 60    You can use this class to build new enumerations
 61    which can be registered using the `Enumerator.register()` method.
 62
 63    This class supports computing sums and products of enumerations:
 64
 65    >>> print(Enumerator(int) + Enumerator(bool))
 66    [0, False, True, 1, -1, 2, ...]
 67
 68    Use `*` to take the product of two enumerations:
 69
 70    >>> print(Enumerator(int) * Enumerator(bool))
 71    [(0, False), (0, True), (1, False), (1, True), (-1, False), (-1, True), ...]
 72
 73    There are other operations.  See below.
 74    """

 76    tiers: typing.Callable[[], typing.Generator[list,None,None]]
 77    """
 78    Generate tiers of values.
 79
 80    >>> list(Enumerator(bool).tiers())
 81    [[False, True]]
 82    """

 84    def __new__(cls, *args):
 85        """
 86        One can initialize a raw enumerator
 87        with a (potentially infinite) generator of finite lists.
 88
 89        >>> Enumerator(lambda: ([x] for x in itertools.count()))
 90        Enumerator(lambda: (xs for xs in [[0], [1], [2], [3], [4], [5], ...]))
 91
 92        >>> Enumerator(lambda: (ps for ps in [[False, True]]))
 93        Enumerator(lambda: (xs for xs in [[False, True]]))
 94
 95        No arguments yield an empty enumerator:
 96        >>> Enumerator()
 97        Enumerator(lambda: (xs for xs in []))
 98
 99        With a type as the sole argument,
100        this queries `register()`ed enumerators:
101        >>> Enumerator(int)
102        Enumerator(lambda: (xs for xs in [[0], [1], [-1], [2], [-2], [3], ...]))
103        """
104        match args:
105            case []:
106                return cls.empty()
107            case [ty] if type(ty) is type:
108                try:
109                    return cls._enumerators[ty]
110                except KeyError:
111                    try:  # tries to infer enumerator from argument types
112                        return cls.cons(ty, *arg_types(ty))
113                    except ValueError:  # no signature
114                        raise TypeError(f"could not infer Enumerator for {ty}")
115            case [ty] if type(ty) in [types.GenericAlias, typing.Union, types.UnionType]:
116                return cls.find(ty)
117            case [tiers]:
118                e = super(Enumerator, cls).__new__(cls)
119                e.tiers = tiers
120                return e
121            case _:
122                raise ValueError(f"too many arguments in Enumerator construction")
123
124    def __iter__(self):
125        return ii.flatten(self.tiers())

128    def choices(cls, *iis):
129        """
130        Builds an enumerator from choices of iterables or items.
131
132        With a selection of atomic items, this returns an enumerator
133        where these values are of the same size:
134
135        >>> Enumerator.choices(False, True)
136        Enumerator(lambda: (xs for xs in [[False, True]]))
137
138        >>> Enumerator.choices(1, 2, 3)
139        Enumerator(lambda: (xs for xs in [[1, 2, 3]]))
140
141        If the single argument is a list,
142        earlier values are considered of smaller size than later values.
143
144        >>> Enumerator.choices([0,2,4,6])
145        Enumerator(lambda: (xs for xs in [[0], [2], [4], [6]]))
146
147        The same happens if a generator is passed as an argument:
148
149        >>> Enumerator.choices(itertools.count)
150        Enumerator(lambda: (xs for xs in [[0], [1], [2], [3], [4], [5], ...]))
151
152        Generators, list and atomic items can be combined:
153
154        >>> Enumerator.choices([1,2,3], False, True)
155        Enumerator(lambda: (xs for xs in [[1, False, True], [2], [3]]))
156
157        Note strings are iterables,
158        nest on lists accordingly:
159
160        >>> Enumerator.choices([1,2,3], ["abc"])
161        Enumerator(lambda: (xs for xs in [[1, 'abc'], [2], [3]]))
162
163        >>> Enumerator.choices([1,2,3], "abc")
164        Enumerator(lambda: (xs for xs in [[1, 'a'], [2, 'b'], [3, 'c']]))
165
166        Enumerators and types are allowed too:
167
168        >>> Enumerator.choices(None, Enumerator(int), bool)
169        Enumerator(lambda: (xs for xs in [[None, 0, False, True], [1], [-1], [2], [-2], [3], ...]))
170        """
171
172        def tierify(obj):
173            if isinstance(obj, Enumerator):
174                return obj.tiers()
175            try:
176                # iter() raises TypeError on non-iterable results
177                return ii.nest(iter(obj()))
178            except TypeError:  # not callable or with non-iterable result
179                try:
180                    return ii.nest(iter(obj))
181                except TypeError:
182                    try:
183                        return Enumerator(obj).tiers()
184                    except TypeError:
185                        return ii.unit(obj)
186
187        def enumerify(obj):
188            if isinstance(obj, Enumerator):
189                return obj
190            else:
191                return Enumerator(lambda: tierify(obj))
192
193        # return cls(lambda: ii.zippend(*[tierify(i) for i in iis]))
194        return Enumerator.sum(*[enumerify(i) for i in iis])

199        This constructs an enumerator
200        for classes that can be directly constructed
201        from the simple cross-product between other types.
202        Just list the class and type arguments:
203
